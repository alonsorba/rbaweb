# Preparación para CMS

## Principio general

Cada sección futura del sitio debe documentarse como si fuera a administrarse desde un CMS, incluso antes de que la tecnología final se defina. Eso evita acoplar contenido fijo al HTML.

## Qué debe registrarse por sección

- Campos editables.
- Tipo de campo.
- Límite de caracteres.
- Orden de aparición.
- Visibilidad o activación.
- Reglas de publicación.
- Imágenes requeridas y proporciones.
- Elementos fijos que no se deben editar.

## Aplicación a la base actual

- El hero de inicio deberá separar título, texto, CTA y estado visual.
- Los bloques informativos deben poder convertirse luego en tarjetas o módulos repetibles.
- El logo y la navegación deben mantenerse como elementos administrables por configuración, no por edición manual del marcado.

## Estado inicial

En esta fase todavía no existe CMS, pero la estructura ya queda preparada para documentar cada campo cuando se comience el desarrollo por secciones.
